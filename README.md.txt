# Salome Garcia — Data Analysis & Visual Storytelling Portfolio

This repository contains the source files for my professional portfolio website, featuring data-analysis projects, visual storytelling, research, and technical documentation.

The site is built as a lightweight static website using HTML and CSS and is hosted with GitHub Pages.

## Live site

[View the portfolio website](https://msalomegarcia.github.io/)

## Portfolio contents

The site will include case studies and visualizations from projects involving:

- Video games sales trends and marketing strategy
- Movie rentals, customer behavior, and online-service launch strategy
- Grocery basket and consumer-purchase analysis
- Influenza-season analysis and healthcare-data storytelling
- Other data-analysis, research, archival, and visual-communication work

## Site structure

```text
.
├── index.html              # Portfolio homepage
├── style.css               # Site-wide styling
├── assets/

│   └── documents/          # PDFs, reports, CV, and downloadable materials

```

## Technologies

- HTML5
- CSS3
- GitHub Pages
- GitHub Desktop for version control and publishing

## Local preview

To preview the website on a computer:

1. Open the repository folder.
2. Double-click `index.html`.
3. The homepage should open in your default web browser.

## Publishing updates

This site is published from the `main` branch through GitHub Pages.

To update the live site:

1. Edit or add files in the local repository folder.
2. Open GitHub Desktop.
3. Review the files listed under **Changes**.
4. Add a clear commit summary.
5. Click **Commit to main**.
6. Click **Push origin**.
7. GitHub Pages will publish the updated version shortly afterward.
